# RadioMaster Kazakh Voice Pack 🇰🇿

**Kazakh language voice pack for RadioMaster radio controllers**

Казахская голосовая локализация для радиопультов RadioMaster.

Проект создан для расширения использования казахского языка в современных технологиях, радиоуправлении, FPV-дронах, робототехнике и техническом образовании.

---

## About the project

This project provides a Kazakh-language voice pack for compatible RadioMaster radio controllers and software.

The voice pack contains system messages, warnings, notifications and other voice prompts translated and recorded in the Kazakh language.

Проект распространяется бесплатно и предназначен для пользователей RadioMaster, желающих использовать казахский язык в голосовых уведомлениях своего оборудования.

---

Основные цели проекта:

## Installation

Инструкция по установке зависит от модели радиопульта, используемой прошивки и версии voice pack.

Перед установкой рекомендуется:

1. Проверить совместимость voice pack с вашей моделью радиопульта.
2. Сделать резервную копию существующих файлов голосовых пакетов.
3. Скачать соответствующую версию voice pack.
4. Скопировать файлы в соответствующую папку голосовых пакетов.
5. Перезапустить радиопульт.
6. Проверить работу голосовых сообщений.

Не используйте файлы, предназначенные для другой версии прошивки или другой структуры voice pack.
